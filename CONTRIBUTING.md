# Contributing

mesimon is currently a single-author project in its pre-v0.1 phase and is not yet accepting
outside contributions.

## The CLA rule (recorded before it is needed)

Per `docs/00-DECISIONS.md` D3a: the project plans a source-available paid team tier alongside the
Apache-2.0 core. To keep relicensing rights intact, **a CLA will be adopted before the first
outside pull request is merged.** No outside PR will be merged before that happens. This rule
exists now, in advance, so it is policy rather than a reaction to any particular contribution.

## Repository boundary

Team-tier code lives only under `team/` (or a separate repository), never inside Apache-2.0
files. Per-file license headers and the `NOTICE` file mark the boundary.
